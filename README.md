# SNS Content Manager

**Just copy a link — recording & downloading start automatically.**
Records TikTok, Instagram and YouTube lives and downloads videos & photos from TikTok, Instagram, YouTube, X and Threads, organized by creator, type and date. Free for Mac and Windows. Made by **VIATOR AI**.

- **Windows** (10/11): extract first → double-click `Install for Windows.bat`

Overview & iPhone guide: https://claude.ai/artifact/NwLnBJVfiDEF9oamDkisGP

## Features
- 📋 **Clipboard auto-download** — live link → recording, post link → download, profile link → whole account
- 🔴 **Live recording** — auto watch, record now, scheduled, and learned regular schedules
- 📱 **iPhone** — send from the Share button; your computer does the work
- 📁 Saved to `Downloads › SNS Content › creator › Live / Videos / Photos`
- Runs in the background, updates its download engines daily
